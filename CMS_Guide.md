HealConnect CMS User Guide
Welcome to the Content Management System (CMS) for HealConnect! This guide explains how to use the Admin Panel to manage Banners, Blogs, and FAQs.

The data you input in these sections is automatically fetched and displayed on the public frontend of the HealConnect application.

1. Managing Banners
Location: Admin Panel > Banners (or navigate to /admin/banners)

Banners are the promotional images and messages that usually appear at the top of the homepage or dashboard.

How to use:
Add a Banner: Click the "Create Banner" or "+" button. You will need to provide:
Image URL: The web address of the banner image.
Link: (Optional) A URL the user will be redirected to if they click the banner.
Title / Subtitle: Optional text to display over the banner.
Active Status: You can toggle whether the banner is currently visible to users.
Edit/Delete: In the table of banners, use the action buttons (edit/trash) to update a banner's details or remove it entirely.
2. Managing Blogs
Location: Admin Panel > Blogs (or navigate to /admin/blogs)

Blogs allow you to publish articles, news, and astrological insights for your users to read on the /blog page.

How to use:
Write a Post: Click to create a new blog post. The fields include:
Title: The headline of your article.
Slug: The URL-friendly version of the title (e.g., understanding-your-kundli). This determines the final link: healconnect.com/blog/understanding-your-kundli.
Cover Image: An image URL to represent the article.
Content: The actual body of the post. Important: The content supports Markdown! You can use # for headers, **text** for bold, and - for bullet points.
Tags: Categorize your post (e.g., "Astrology", "Health").
Status: Set it to PUBLISHED for users to see it, or DRAFT if you are still working on it.
View Live: Once published, the post will automatically appear on the public /blog page.
3. Managing FAQs (Frequently Asked Questions)
Location: Admin Panel > FAQs (or navigate to /admin/faqs)

FAQs are displayed on the public /faq page to help users resolve common issues without needing to contact support.

How to use:
Add a Question: Create a new FAQ entry by providing:
Category: Group questions together (e.g., "Payments", "Consultations", "Account").
Question: The question the user might ask.
Answer: The solution or explanation.
Order/Priority: A number to determine the sequence in which the questions appear (lower numbers usually appear first).
Active Status: Toggle whether this question is visible.
Organization: The public FAQ page automatically groups the questions by the Category you provided, creating a clean accordion layout for users.
